# Cycle-GAN-re-implementation-Project
PyTorch re-implementation of CycleGAN for unpaired image-to-image translation (horse↔zebra). Features a 9-block ResNet generator, 70×70 PatchGAN discriminator, LSGAN loss, and an image pool. Includes an ablation study on identity loss and cycle-consistency weight, evaluated with FID and qualitative comparison.
